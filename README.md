# MealWebReact

Bu proje, kullanıcıların farklı yemek tariflerine göz atmasını sağlayan basit bir **yemek tarifi web uygulamasıdır**. React.js ile geliştirilmiştir ve kullanıcı dostu bir arayüz sunar.

## 🚀 Özellikler

- 🍔 Günlük popüler yemek tarifleri
- 🔍 Tarifler arasında arama yapabilme
- 📦 TheMealDB API entegrasyonu
- ⚡ Hızlı ve duyarlı tasarım (Responsive)
- 🎯 Temiz ve modern kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

- [React](https://reactjs.org/)
- [React Router](https://reactrouter.com/)
- [Axios](https://axios-http.com/)
- [TheMealDB API](https://www.themealdb.com/)
- [Bootstrap 5](https://getbootstrap.com/)

## 🔧 Kurulum ve Çalıştırma

```bash
# Projeyi klonla
git clone https://github.com/JrCiko/MealWebReact.git
cd MealWebReact

# Gerekli bağımlılıkları yükle
npm install

# Uygulamayı başlat
npm start
